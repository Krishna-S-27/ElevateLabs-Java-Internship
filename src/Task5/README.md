# Task 5: Bank Account Simulation

## Objective
Simulate basic bank operations using Java OOP with class-based design and transaction tracking.

## Deliverables
- `Account.java`: encapsulates account data, `deposit`, `withdraw`, balance handling, and transaction history.
- `BankAccountSimulation.java`: menu-driven CLI runner to perform transactions.

## Features
- Create an account with account number, holder name, and initial balance.
- Deposit and withdraw money with validation.
- Prevent invalid amounts and overdraft withdrawals.
- View current account balance.
- View full transaction history with timestamps.

## Tech Used
- Java
- VS Code / Terminal

## How to Run
From project root (`D:\ElevateLabs-Java-Internship`):

```powershell
javac -d out src\Task5\*.java
java -cp out Task5.BankAccountSimulation
```
